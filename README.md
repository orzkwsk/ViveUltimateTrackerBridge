# ViveUltimateTrackerBridge

VIVE Ultimate Tracker backend/bridge project for operating trackers without VIVE Hub.

## Initial scope

- Bypass VIVE Hub and obtain/use tracker data through a custom backend/bridge.
- Reuse findings from the existing PICO tracker bridge and prior VIVE Ultimate Tracker research where applicable.
- Wi-Fi based tracker-count-limit bypass is intentionally out of scope for the initial implementation and will be handled as a later phase.
